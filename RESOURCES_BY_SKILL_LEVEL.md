# Resources by Skill Level

## Beginner

Start with concepts and safe targets:

- [Android Developers](https://developer.android.com/)
- [Android security](https://source.android.com/docs/security)
- [JADX](https://github.com/skylot/jadx)
- [Apktool](https://github.com/iBotPeaches/Apktool)
- [Wireshark](https://www.wireshark.org/)
- [CyberChef](https://github.com/gchq/CyberChef)
- [OverTheWire](https://overthewire.org/wargames/)
- [PortSwigger Web Security Academy](https://portswigger.net/web-security)

## Intermediate

Build a controlled workflow:

- [Ghidra](https://github.com/NationalSecurityAgency/ghidra)
- [Frida](https://github.com/frida/frida)
- [MobSF](https://github.com/MobSF/Mobile-Security-Framework-MobSF)
- [mitmproxy](https://github.com/mitmproxy/mitmproxy)
- [Androguard](https://github.com/androguard/androguard)
- [OWASP MAS](https://mas.owasp.org/)
- [crackmes.one](https://crackmes.one/)
- [CTFtime](https://ctftime.org/)

## Advanced

Study internals and build tooling:

- [Qiling](https://github.com/qilingframework/qiling)
- [Unicorn](https://github.com/unicorn-engine/unicorn)
- [Capstone](https://github.com/capstone-engine/capstone)
- [Unidbg](https://github.com/zhkl0228/unidbg)
- [Rizin](https://github.com/rizinorg/rizin)
- [YARA](https://github.com/VirusTotal/yara)
- [MITRE ATT&CK](https://attack.mitre.org/)
- [Trail of Bits training](https://github.com/trailofbits/training)

Skill labels are guidance, not a ranking. A beginner can use an advanced tool with a good tutorial, and experienced researchers should still verify assumptions in simple controlled tests.
